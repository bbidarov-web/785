# Правила для Claude Code — Контур 785

## Контекст
Переносим рабочий HTML-прототип (`prototype/`) в продакшн-приложение с сервером и БД. Прототип — эталон вида и поведения: при расхождении сверяйся с ним, а не придумывай своё. Архитектура — `SERVER.md`, продукт и дизайн-токены — `README.md`.

## Неизменные правила продукта
- **Арендатор — клиника, ключ — ИНН** (10 или 12 цифр, контрольная сумма ФНС). ИНН арендатора берётся **только из сессии**, никогда из параметра запроса.
- **Права проверяются на сервере на каждом эндпоинте** по матрице `ROLES` из `prototype/platform.js`. Интерфейс только скрывает недоступное — это не защита.
- **Журнал действий — только добавление.** Никаких UPDATE и DELETE, отказ в праве тоже пишется.
- **Вторая рука:** семь необратимых операций — запрос и подтверждение разными пользователями (список в `SERVER.md`, раздел 4).
- **Выдача документов:** шаблон отдаётся только при наличии записи выдачи для этой клиники.
- **Параллельные правки:** запись с проверкой `version`, конфликт — слияние или явная ошибка, но не молчаливое затирание.
- **Персональные и медицинские данные** хранятся в РФ (152-ФЗ). Не логировать пароли, коды, содержимое документов.

## Интерфейс
- Язык интерфейса — русский. Тексты, подписи и сообщения об ошибках брать из прототипа дословно.
- Дизайн-токены — в `README.md`: Manrope + IBM Plex Mono, палитра на `#157f76` / `#10201f` / `#eef1f1`.
- Адаптивность обязательна: выдвижное меню до 1100 px, карточки вместо таблиц до 720 px, кнопки от 44 px, поля от 16 px на сенсорных экранах.
- Даты в интерфейсе — ДД.ММ.ГГГГ. Суммы — с пробелом-разделителем и ₽.

## Работа
- Переносить экран за экраном, после каждого сверять с прототипом на 390, 820 и 1440 px.
- Не удалять эталонные справочники из прототипа — это начальные данные миграции.
- Места, где нужен сервер, отмечены в прототипе комментарием `// SERVER:`.
